# AI instructions — quinte-school-project

Read in this order before doing anything: `docs/project-brief.md` (authoritative direction and founder constraints), `docs/decision-log.md` (approved decisions only), `docs/open-questions.md`, then the topic file(s) for the task. `README.md` holds current status.

Rules:
- The repository is public. Never add identifiable child records, family benefit details, or confidential donor information.
- No outreach to any external party (owners, boards, funders, businesses, officials) without the founder's explicit authorization. Research is desk research.
- Label material findings: **VERIFIED** (primary source read; give link and access date), **SECONDARY** (reputable commentary), **ESTIMATE** (show basis and formula), **PROPOSAL** (recommendation, not approved), **ASSUMPTION** (planning assumption), **FOUNDER DECISION** (from the decision log), **CONFIRM** (needs confirmation with a named authority).
- Separate statutory requirements, professional recommendations, planning assumptions and founder decisions.
- Record recommendations in topic files and `docs/open-questions.md`; only the founder adds to `docs/decision-log.md`.
- Do not re-research settled questions: check `sources/source-register.md` and the v1 notes in `reports/2026-10-14-v1-research-notes/` first. Add every source used to the source register.
- Finances: `finance/model.py` is the reproducible model; `finance/assumptions.md` holds every input with source and price year; `finance/outputs.md` is generated. Never edit outputs by hand.
- Reports in `reports/` are dated snapshots; never edit them. Write a new dated file instead.
- Work on a `research/*` branch; do not rewrite `main` history.
