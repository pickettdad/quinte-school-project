# Quinte tuition-free school project

Feasibility and design work for a not-for-profit, tuition-free, five-day school in Belleville, Ontario for elementary and secondary students with intellectual and developmental learning needs. Public repository: no child, family-benefit or confidential donor information.

## Current status (2026-10-15)
Phase 2 first pass complete on branch `research/2026-10-phase2`: 50-student design, v1 audit, rebuilt operating model, property/transport ranking, prospect register. Latest summary: `reports/2026-10-15-phase2-summary.md`. Headline: gross cost ≈ $2.65M/yr at 50 students (2026 prices), remaining fundraising need ≈ $2.3–2.5M/yr; three founder decisions pending (staffing design, premises track, funding test).

## Structure
- `docs/project-brief.md` — authoritative direction and constraints · `docs/decision-log.md` — approved decisions only · `docs/open-questions.md` · `docs/government-questions.md` (running list for MPP conversation)
- `research/` — topic files: educational-design, admissions-criteria, premises, transportation, staffing-volunteers, public-services-partners, financing
- `finance/` — `assumptions.md`, `model.py` (reproducible), `outputs.md` (generated), `v1-audit.md`
- `funding/prospect-register.md` — qualified prospects (committed / plausible / speculative)
- `sources/source-register.md` · `reports/` — dated snapshots (v1 report and notes preserved unchanged) · `reference/` — public documents
- `CLAUDE.md` — AI instructions pointing to the authoritative documents

Labels used everywhere: VERIFIED · SECONDARY · ESTIMATE · PROPOSAL · ASSUMPTION · FOUNDER DECISION · CONFIRM.
